السورس الكامل - نسخة نظيفة لإعادة الرفع
===========================================

هذا كل شي يحتاجه الريبو من الصفر، كله بتخطيط مسطح (كل الملفات بجذر
الريبو، بدون مجلد src) لأنك ترفع عن طريق واجهة GitHub.

وش بالزيب؟
------------
- 26 ملف .cs (كل كود البرنامج، فيها احدث التعديلات: شكل السلايدرات،
  كرت Bass Boost/Stereo/Surround، نظام الاشتراك الجديد عبر الموقع،
  مؤشر الماوس مع تسجيل تشخيصي)
- EaxReverbEngine.csproj  -> نسخة مسطحة (*.cs بدل src\**\*.cs)
- Confuser.crproj         -> اعدادات التشفير الآمنة (rename + constants فقط)
- build.yml               -> خطوات GitHub Actions (لازم يروح داخل
                              .github/workflows/build.yml، مو بجذر الريبو)

خطوات الرفع النظيف
---------------------
1. احذف كل الملفات اللي بجذر الريبو "343243" (عدا .github لو تبي تحافظ
   عليه - بس الافضل تحذف كل شي وترفع من هذا الزيب عشان ما يصير تداخل).
2. ارفع كل ملفات الـ .cs (الـ26) + EaxReverbEngine.csproj + Confuser.crproj
   مباشرة بجذر الريبو (مو داخل مجلد).
3. ارفع build.yml داخل مسار .github/workflows/build.yml (سوي المجلدات
   هذي يدوي لو GitHub ما خلاك ترفع مباشرة بمسار متداخل - اضغط "Add file"
   واكتب المسار كامل .github/workflows/build.yml وهو يسوي المجلدات تلقائي).
4. تأكد ملف License.cs فيه رابط موقعك الصحيح بدل
   "https://YOUR-LICENSE-SERVER.example.com" (لو ما سويت الموقع بعد،
   خله مؤقتا كذا وبدله بعدين وارفعه من جديد).
5. انتظر الـ Actions يبني وحمل الـ DLL.

ملاحظة عن مؤشر الماوس (لسا اسود)
-----------------------------------
ضفت تسجيل تشخيصي بالكود (ملف Skin.cs). بعد ما تبني وتجرب، افتح الملف:

    %APPDATA%\CreativeEAXSettings\engine.log

ودور على اسطر تبدأ بـ "cursor:" وابعثها لي كاملة. فيها بالضبط وين
المشكلة (فشل القراءة؟ فشل التحميل؟ اي ثريد يشتغل عليه؟) بدل ما نخمن.
